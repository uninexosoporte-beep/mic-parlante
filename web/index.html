¿Cómo se instala el APK?
  1. Toca Descargar app Android y abre el archivo cuando termine.
  2. Si Android avisa de "fuente desconocida", toca Configuración → Permitir de esta fuente.
  3. Toca Instalar. Si aparece Play Protect, elige Instalar de todas formas.
  4. Conecta tu parlante Bluetooth, abre Mic Parlante y acepta el permiso de micrófono.
